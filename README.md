# BMI Calculator

## 📝 Overview

**BMI Calculator** is a simple and easy-to-use web application built using **React.js** that helps users calculate their Body Mass Index (BMI). By inputting their weight and height, users can instantly determine whether they fall under the categories of underweight, normal weight, overweight, or obese based on BMI standards.

This app is designed to provide users with quick health insights based on their BMI, making it a helpful tool for fitness enthusiasts, health professionals, and anyone interested in tracking their body metrics.

🔗 [Live Demo](https://astr1cs.github.io/BMI-calculator/)

## 🚀 Features

- **BMI Calculation**: Input weight and height to calculate your BMI.
- **Clear BMI Categories**: Displays your BMI and the corresponding category (Underweight, Normal, Overweight, or Obese).
- **User-friendly Interface**: A clean, minimal design for easy interaction and data entry.
- **Responsive Design**: The app is fully mobile-friendly and adapts perfectly to different screen sizes.
- **Fast and Efficient**: Instantly calculates your BMI with no delays.

## 🛠️ Technologies Used

- **React.js**: A JavaScript library for building user interfaces.
- **CSS**: Custom styles for a responsive and clean design.
- **HTML**: For structuring the application.
